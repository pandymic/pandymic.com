COMP 1950 | Week 2 Quiz

  1. What does HTML stand for?
    1. Hyperlinks and Text Markup Language
    2. Hyper Text Markup Language
    3. Home Tool Markup Language
  2. What does X in XHTML stand for?
    1. eXtended
    2. eXtensible
    3. eXpanded
  3. What does CSS stand for?
    1. Complete Style Sheet
    2. Computing Style System
    3. Cascading Style Sheets
  4. What does DTD stand for?
    1. Document Term Declaration
    2. Document Type Definition
    3. Defined Text Document
  5. Choose the correct HTML tag for the largest heading
    1. <h6>
    2. <h1>
    3. <head>
    4. <heading>
  6. What is the correct HTML tag for inserting a line break?
    1. <lb>
    2. <break>
    3. <br>
  7. What is the correct HTML for adding a background color?
    1. <background>yellow</background>
    2. <body bgcolor="yellow">
    3. <body color="yellow">
  8. What is the correct HTML for making a hyperlink?
    1. <a url="http://www.bcit.ca">BCIT</a>
    2. <a href="http://www.bcit.ca">BCIT</a>
    3. <a>http://www.bcit.ca</a>
    4. <a name="http://www.bcit.ca">BCIT</a>
  9. How can you make an e-mail link?
    1. <a href="a***@my.bcit.ca">
    2. <mail href="a***@my.bcit.ca">
    3. <a href="a***@my.bcit.ca">
    4. <mail>a***@my.bcit.ca</mail>
  10. How can you open a link in a new browser window?
    1. <a href="url" target="new">
    2. <a href="url" target="_blank">
    3. <a href="url" new>
  11. How can you make a list that lists the items with 1, 2, 3...?
    1. <list>
    2. <dl>
    3. <ol>
    4. <ul>
  12. What is the correct HTML for inserting an image?
    1. <img>image.gif</img>
    2. <image src="image.gif">
    3. <img href="image.gif>
    4. <img src="image.gif">
  13. XHTML is a Web standard
    1. False
    2. True
  14. HTML will be replaced by XHTML
    1. False
    2. True
  15. What is a correct XHTML tag for a line break?
    1. <br>
    2. <br />
    3. <break/>
  16. What is the correct XHTML for an attribute and its value?
    1. width=80
    2. WIDTH="80"
    3. width="80"
    4. WIDTH=80
  17. Complete the sentence: A 'valid' XHTML is said to be…?
    1. well-formed.
    2. uploaded in binary format
    3. not past it's due date
  18. What is the correct HTML for referring to an external style sheet?
    1. <stylesheet>mystyle.css</stylesheet>
    2. <style src="mystyle.css">
    3. <link rel="stylesheet" type="text/css" href="mystyle.css">
  19. Which is the correct CSS syntax?
    1. {body;color:black}
    2. body:color=black
    3. {body:color=black(body}
    4. body {color: black}
  20. Using CSS, how do you display hyperlinks without an underline?
    1. a {text-decoration:no underline}
    2. a {text-decoration:none}
    3. a {underline:none}
    4. a {decoration:no underline}
